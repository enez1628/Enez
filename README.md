# Bird Match Puzzle 🐦

Renkli blok patlatma/eşleştirme mobil puzzle oyunu - Flutter ile geliştirildi.

## Özellikler

- **Çekirdek Oynanış**: Aynı renk blokları eşleştirip patlatma (2+ bağlı blok)
- **Seviye Sistemi**: Artan zorluk, farklı hedefler ve hamle sınırı
- **Ada/Köy İnşa**: Yıldız harcayarak binalar yap
- **Etkinlikler**: Günlük görevler, eşleştirme görevi, battle pass
- **Mağaza**: Güç-up paketleri ve altın
- **Ödül Sistemi**: Kumbara, hazine adası, günlük dönüş ve daha fazlası

## Kurulum

```bash
# Flutter SDK gerekli (3.24+)
flutter pub get
flutter run
```

## Derleme

```bash
# Android APK
flutter build apk

# iOS (macOS gerekli)
flutter build ios

# Web
flutter build web
```

## Teknoloji

- Flutter 3.24.5
- Dart 3.5.4
- Android SDK 34
- Paket: `com.enez.bird_match_puzzle`
